# Protein-Prophet: Multi-Threshold Benchmark for Protein Sequence Classification

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-1.12%2B-ee4c2c)
![License](https://img.shields.io/badge/License-MIT-green)

这是一个系统性的蛋白质序列分类基准测试项目。本项目通过 CD-HIT 聚类产生不同序列同源性阈值（0.4, 0.5, 0.6, 0.7）的子集，评估深度学习模型（MLP）在处理不同冗余度数据时的稳健性与泛化能力。

This is a systematic benchmark project for protein sequence classification. It evaluates the robustness and generalization of Deep Learning models (MLP) across different sequence identity thresholds (0.4, 0.5, 0.6, 0.7) generated by CD-HIT.

## 🚀 核心流程 (Core Pipeline)

1. **数据去冗余 (Data Deduplication)**: 使用 CD-HIT 生成不同阈值的 FASTA 文件。
2. **特征编码 (Encoding)**: 见 `encode.ipynb`，支持预训练蛋白质语言模型嵌入。
3. **特征选择 (Feature Selection)**: 见 `do_mrmd3.ipynb`，利用 MRMD3 算法进行特征降维与重要性分析。
4. **特征分析 (Feature Analysis)**: 见 `features_analysis.ipynb`，分析特征分布及其对预测的贡献。
5. **基准测试 (Benchmarking)**: 在 5 个随机种子下进行 8:2 划分，并采用早停机制（Early Stopping）训练 MLP。

## 📊 实验结果 (Benchmark Results)



根据不同 CD-HIT 阈值的验证集表现：
- **0.4 阈值**: 代表最严苛的非同源测试，模型展现了真实的生物特征学习能力 (MCC ≈ 0.80)。
- **0.6/0.7 阈值**: 表现最优，适用于探索模型性能上限。

## 📂 文件结构 (File Structure)

- `encode.ipynb`: 序列编码与嵌入提取 (Sequence embedding extraction)。
- `do_mrmd3.ipynb`: 基于 MRMD3 的特征降维 (Feature reduction via MRMD3)。
- `features_analysis.ipynb`: 特征相关性与统计分析 (Statistical analysis of features)。
- `model.ipynb`: 核心训练代码，包含多阈值对比逻辑。
- `requirements.txt`: 项目依赖包清单。
